# REN Lab · Endoscopic Autonomy

Project pages for the REN Lab (Intelligent Medical Mechatronics, Department of Electronic
Engineering, The Chinese University of Hong Kong) work on autonomous flexible endoscopy.

**Live site:** https://ngchikit.github.io/renlab-endoscopic-projects/

| Project | Paper |
|---|---|
| **EndoVLA** — Dual-Phase Vision-Language-Action for Precise Autonomous Tracking in Endoscopy | CoRL 2025 · [PMLR v305](https://proceedings.mlr.press/v305/kit25a.html) |
| **CAN** — Contact-Aided Navigation of Flexible Robotic Endoscope Using Deep Reinforcement Learning in Dynamic Stomach | IEEE ROBIO 2025 · [IEEE Xplore](https://ieeexplore.ieee.org/document/11376000/) · [arXiv:2509.00319](https://arxiv.org/abs/2509.00319) |
| **EndoLIFT** — Language-Disambiguated Latent-Conditioned Rectified Flow for Bidirectional Endoscopic Control | Preprint · [arXiv:2608.20478](https://arxiv.org/html/2608.20478v1) |

Related: [EndoWAM](https://jinsonglin-cuhk.github.io/renlab-project-homepages/EndoWAM/) ·
[Lab website](http://www.labren.org/mm/)

## Structure

Static site, no build step. `index.html` is the project index; `endovla.html`, `can.html` and
`endolift.html` are the project pages; everything shares `style.css`. Media lives in `assets/`
(`assets/logos/` for institution marks, `assets/people/` for team photos).
